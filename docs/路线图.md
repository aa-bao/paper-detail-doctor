## B 阶段 · 分批升级

优先升 B（最通用、复用率最高）：

1. **引注模块（L2）** —— 三级优先的体例解析、多种编码制支持
2. **模板提取** —— 体例规则的自动识别（从范文反推规则而非人工填）
3. **一致性核对** —— 锚点抽取与 L2 语义判定的稳定性

可以长期留在 A 的：

- 项目专属的一次性替换映射（标题平实化等）—— 走 `assets/rules/*.yaml`，不写死在代码里

---

## 验收标准（封装完成的定义）

必须能对**一篇与本项目完全无关的论文**跑通全链路，且**不改任何脚本代码，只改配置**：

1. 指定 docx（或 md 目录）+ 参考文献表 → 一键渲染引注 / 建立跳转
2. `audit.py` 出报告 → 每条带定位、期望/实际对照、标准来源
3. `plan.py` 出可编辑计划 → `apply.py` 执行 → 幂等复跑结果一致
4. 字数统计报出双口径 + 分章配额差
5. 页眉/目录/PDF 导出链路可用
6. 金标准跑分出三指标数字
