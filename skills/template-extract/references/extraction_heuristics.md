# 提取启发式与置信度判定

图片与 PDF 无法给出「段前 12 磅」这种精确值，必须靠推断。这份文档定义
**怎么推、推到什么程度要停下问人**。

## 1. 置信度三档

| 档位 | 判定标准 | 处理方式 |
|---|---|---|
| **high** | 规范的**文字部分明确写出**，或 docx 无损读出 | 直接采纳 |
| **medium** | 由样张版面比例 / 常规排版惯例推断，误差有限 | 采纳，但列入报告 |
| **low** | 规范完全未提，取了常见默认值 | **必须列入 `open_questions`，请用户确认** |

规则：**宁可标 low 也不要猜得像真的**。用户的信任建立在「哪些是原文、哪些是我推的」这条界线上。

## 2. 一定要「文字规范 + 样张」互相印证

很多学校的模板是「前几页讲规范 + 后面给样张」。这两者互补性极强：

| 信息 | 从哪读 | 为什么 |
|---|---|---|
| 段前段后磅值、行距、缩进字符 | **文字规范** | 样张里根本看不出来 |
| 字体、字号档位、加粗、对齐 | **样张**（+ 文字规范） | 样张能验证文字描述是否真被落实 |
| 编号形式（1.1 vs 一、） | 两者都要看 | 文字里常给多个可选方案，样张才说明**实际用哪个** |
| 表格线宽（1.5 磅 / 0.5 磅） | **文字规范** | 样张肉眼分不出 1.5 与 1.0 磅 |

若两者冲突，**以文字规范为准**，并在报告里记录冲突点。

## 3. 图片（视觉）推断规则

### 字号推断
1. 先在样张里找出**正文段落**，其字号记为基准（通常是五号或小四）。
2. 标题字号按与正文的**比例**判定：比正文大 1 档 = 小四→四号；大 2 档 = 小四→三号。
3. 用「号↔磅」表落到具体磅值，标 `medium`。

⚠️ 图片是位图，**无法反推原始磅值**，只能定档位。若样张分辨率低到分不清档位，标 `low`。

### 加粗判定
- 汉字加粗在低分辨率图里不明显。判据：笔画明显变粗 + 与同字号正文对比。
- 不确定就标 `medium` 并在报告里注明「疑似加粗」。

### 对齐判定
- 用文本块的水平位置判断：居中 ≈ 左右留白对称；顶格 ≈ 左边界贴版心。
- 缩进量可用「字符宽 ≈ 该字号全角宽度」估算，标 `medium`。

### 边框判定（表格）
- 三线表特征：**只有 3 条横线**（顶、表头下、底），**没有竖线**。
- 磅值无法从图片判定 → 必须从文字规范读，否则标 `low` 并问用户。

## 4. PDF 推断规则

`extract_from_pdf.py` 会输出字号直方图（按字符数加权）。读法：

1. **字符数最多的字号 = 正文基准**（正文占版面最大比例）。
2. 比基准大的档位，从大到小对应 h1、h2、h3……（标题字号必然递减）。
3. 用 span 的 bbox 中心判断居中。
4. 粗体由 `flags` 位判定（bit4/bit5）。

**PDF 拿不到的东西（必须问用户）**：
- 段前 / 段后磅值
- 首行缩进字符数
- 页边距（可粗略反推，但受页眉页脚干扰）
- 表格边框磅值

## 5. DOCX 路径：不需要推断

`.docx` 是带样式表的 XML 包，直接读即可拿到**真值**，`overall_confidence = high`。
唯一需要注意的坑：

- **派生样式**：`一级标题` 常 `basedOn="Heading 1"`，大纲级别在基样式上，
  读取时必须沿 `w:basedOn` 上溯（`extract_from_docx.py` 已处理）。
- **主题字体**：若字体写的是 `+mn-lt` / `+mj-ea`，说明用的是主题字体，
  需读 `word/theme/theme1.xml` 才能确定实际字体名。
- **`w:firstLine` vs `w:firstLineChars`**：前者是磅值，后者才是「字符」语义；
  中文模板几乎都用后者，若读到前者要换算并标注。

## 6. 报告必写的三段

生成的提取报告里必须包含：

1. **来源对照**：每条规则标注来自哪一页（如 `p2 §7(1)`、`p7 样张`）。
2. **置信度**：逐字段标注 high / medium / low。
3. **待确认清单**（`open_questions`）：把所有 low 项集中列出，说明当前取值的理由，
   明确请用户确认或修正。

最后一句必须诚实：**「图片/PDF 路径存在推断成分，精确磅值请以文字规范或人工确认为准」**。
